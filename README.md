# D’Salms V12.0 — Definitive Brand Experience
Sitio estático (HTML5, CSS3, JavaScript modular), sin build ni dependencias externas. Tipografías Kalnia y DM Sans incluidas en `fonts/`.
- 17 páginas: `index.html` y 16 carpetas con `index.html`.
- `css/`: tokens, base, nav, components, motion, home. `js/`: core, animations, components.
- `tools/build_pages.py`: generador opcional de las páginas (no hace falta para publicar).
- Estado y pendientes: `docs/ESTADO_DEL_PROYECTO.md`. Publicación: `docs/PUBLICACION_GITHUB.md`.
